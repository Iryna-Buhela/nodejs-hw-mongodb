# Node.js REST API with MongoDB

A RESTful API built with **Node.js**, **Express**, and **MongoDB** for managing contacts.  
Supports authentication, image uploading, pagination, data validation, and comprehensive error handling.

## 🚀 Features
- User registration & login (JWT authentication)
- CRUD operations for contacts
- Avatar upload (Cloudinary or local upload)
- Request validation using Joi
- Mongoose models & pagination
- Error-handling middleware
- Environment-based configuration
- Swagger API documentation (Swagger UI)

## 🧰 Tech Stack
- **Node.js**
- **Express**
- **MongoDB / Mongoose**
- **Joi**
- **Multer**
- **Cloudinary** (optional)
- **Swagger / OpenAPI**
